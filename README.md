# DIAW - Desenvolvimento e Integração de Aplicações Web

Repositório com as atividades, trabalhos e projetos desenvolvidos na disciplina de **Desenvolvimento e Integração de Aplicações Web**, do curso de Engenharia de Software.

## 📚 Sobre a disciplina

A disciplina aborda o desenvolvimento de aplicações web modernas, cobrindo desde o back-end até o front-end, incluindo a construção e integração de APIs.

## 🛠️ Tecnologias utilizadas

- **Java**
- **Spring Boot**
- **Thymeleaf**
- **React**
- **APIs REST**
- **HTML / CSS / JavaScript**

## 📁 Estrutura do repositório

```
diaw/
├── atividades/       # Exercícios e atividades práticas
├── trabalhos/        # Trabalhos avaliativos
├── projetos/         # Projetos maiores desenvolvidos ao longo da disciplina
└── README.md
```

> A estrutura pode ser ajustada conforme os conteúdos forem sendo adicionados.

## 🚀 Como executar os projetos

Cada pasta de atividade/projeto pode conter seu próprio README com instruções específicas. De modo geral:

### Projetos back-end (Spring Boot)

```bash
cd caminho/do/projeto
mvn clean install
mvn spring-boot:run
```

### Projetos front-end (React)

```bash
cd caminho/do/projeto
npm install
npm start
```
